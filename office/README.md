# Office and Adobe notes

This folder holds light helpers around desktop app inventory. Full Intune Win32 packaging samples for Microsoft 365 Apps live in the companion `intune-home-lab` repository.

## Ideas for a home lab

1. Confirm Click to Run channel and build with `Get-OfficeClickToRunInfo.ps1` in `../windows`.
2. Keep Adobe Creative Cloud or Reader deployment silent switches in a private runbook until you have tested them on a throwaway VM.
3. Document the expected install path and detection rule before you wrap anything as Win32 content.
