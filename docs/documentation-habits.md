# Documentation habits for IT admin labs

Good notes save hours when you revisit a change months later.

1. Record the purpose of each script in one short paragraph at the top of the file.
2. Capture the expected detection rule before you package a Win32 app.
3. Keep a private change log for tenant specific values such as group names and scope tags.
4. Prefer screenshots of the Intune blade with personal data cropped out.
5. When you export a security product policy, strip tenant and resource identifiers before the file leaves your private store.
6. Review shared Drive folders for credential JSON, MFA backup codes and mailbox reports on a regular schedule.
